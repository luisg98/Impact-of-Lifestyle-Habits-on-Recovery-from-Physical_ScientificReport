# Post-COVID-19 Recovery: Lifestyle Habits Analysis

Statistical analysis of lifestyle habits and post-COVID-19 symptom recovery across 193 participants (ages 16–76). Outcome variables: anxiety, stress, and fatigue.

Key findings: pre-COVID physical exercise reduced anxiety; post-COVID sleep quality correlated with lower stress; perceived pre-infection fatigue was a significant anxiety predictor.

Methods: descriptive statistics, correlations, and regression models.
